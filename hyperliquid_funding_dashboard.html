ランキングの読み方
  • ファンディングキャリー・Perp差分の両方の候補を横断し、APRだけでなく出来高上限・送金/デペッグリスク・直近の市場インテリジェンス(取引所の障害・ハッキング等)を加味した composite_score で並べ替えている。
  • 「推奨配分」は総運用資金・1ポジション上限・取引所別上限・銘柄別上限・24h出来高の一定比率、という複数の制約のうち最も厳しいものを適用し、上位候補から順に貪欲法で割り当てた金額。既に他候補で取引所/銘柄の上限に達すると $0 と表示される(次点候補として記録は残す)。
  • この計算はあくまで機械的な目安であり、投資助言ではない。発注前に必ず自分で板の厚み・手数料・清算リスクを確認すること。

戦略メモ
  • APRは各取引所の funding 履歴 API から取得した直近3日間の実績平均を年率換算した値。瞬間値だけでなく安定性を重視している。
  • funding平均がプラス → 現物「買い」+ Perp「ショート」。マイナス → 現物「売り」+ Perp「ロング」。ただし各取引所の spot は原則フルコラテラルで新規空売りができないため、マイナス側は保有現物の売却以外では実行できない。
  • 同一銘柄に複数の spot ペアが存在する場合は、24h出来高が最大のものだけを採用(出来高ゼロの死んだペアを除外するため)。
  • funding 間隔は取引所・銘柄ごとに異なる (Hyperliquidは1時間固定、Asterは銘柄により1〜8時間)。各取引所の実際の間隔を検出してから年率換算しているため、取引所間でAPRを直接比較できる。
  • k プレフィックスの Hyperliquid Perp (例: kBONK) は1コントラクト=対象トークン1000枚分の建値のため、ベーシス計算時に1000で正規化している。
  • Injective (Helix) のみ簡易実装: APIがgRPC-Webベースで価格・出来高・funding履歴の正しいRESTエンドポイントが未特定のため、現在のfunding rateのみを参考値として掲載。価格・ベーシス・出来高フィルタなし(表内は — 表示)。実際に取引する前に自分でHelix上の板の厚みを確認すること。
  • このページはスナップショットで、自動更新はされない。最新化するには Claude に再取得を依頼すること。

戦略メモ (Perp差分スキャナー)
  • 現物を使わず、無期限先物同士を逆方向に建ててファンディングレートの「差分」を取る戦略の候補一覧。両脚とも証拠金取引のためレバレッジをかけられる。
  • 取引所間: 同じ銘柄のperpが複数取引所に上場している場合、fundingが高い取引所でショート・低い取引所でロングする。取引所間の送金・出金リスク、価格が一瞬ズレるタイミングリスクがある。
  • 同一取引所: 同一取引所内で決済通貨違いの複数perp契約がある場合 (例: Asterの BTCUSDT/BTCUSD1/BTCU) の差分。送金リスクは無いが、決済通貨自体のデペッグリスクがある。
  • まず瞬間値でスクリーニングし、有望な上位候補のみ3日間の実績平均で再検証している。「3日実績」列が空欄の行は上位候補外のため未検証(瞬間値のみ、参考程度に見ること)。3日実績がマイナスに転じた行は、瞬間値ほど安定した機会ではないことを示す。
  • Injective が絡む行は瞬間値スクリーニング段階では出来高不明(「参考情報」)。上位候補になった行は実際の約定履歴から出来高を検証し、最小流動性($20,000)未満と判明した場合は上の「除外した候補」に回している。Injectiveは誰でも無許可でデリバティブ市場を作成できるため、データ取得元のAPIはHelix(公式フロントエンド)が採用していない市場も"active"として返すことがある(実例: AR/USDC PERPはAPI上activeだがHelixの検索には出てこないことを確認済み)。出来高が閾値未満かどうかをHelix非採用市場の代理指標として使っている。
  • 両脚とも証拠金取引のため、清算リスクが両側に発生する。特に取引所間の差分を狙う場合は2つの取引所の証拠金維持率を両方監視する必要がある。

エッジ・ラボについて
  • edge_playbook.md にクリプト全般の「稼ぐためのエッジ」をカテゴリ別にカタログ化している。ファンディング/ベーシス系以外(新規上場、エアドロップ、清算カスケード等)も対象。検証状況は「自社データで検証済み」「文献ベース」「未検証」「検証不可(データ基盤なし)」を正直に区別している。
  • 新規上場検知は各取引所の現在の全perp銘柄一覧を前回実行時と比較する差分方式。異常な価格乖離はspot/perp間のベーシスが±1.5%を超えた行を抽出している。どちらも認証不要の公開データのみで毎時自動実行。
  • 「学ぶ・発見・分析・新しいエッジを生み出す」という定性的な調査は自動化できないため、edge-researcher サブエージェントにオンデマンドで依頼する運用。
市場インテリジェンスについて
  • リスクイベントは DeFiLlama の公開ハッキング一覧から、対象取引所名と完全一致する項目のみを抽出している(名前が似ているだけの無関係なプロジェクトを誤って拾わないよう、部分一致は行っていない)。
  • トレンド銘柄は CoinGecko の Trending API から取得。値上がり期待ではなく「将来 Perp が新規上場されるかもしれない銘柄」の目安として見ること。
  • この2つは毎時の自動更新に組み込まれた機械的な収集のみ。「新興取引所は検討に値するか」等の定性的な深掘りは market-intel-analyst サブエージェントにオンデマンドで依頼し、その結果は market_intel_notes.md に蓄積される(推奨ランキングのリスク評価にも反映される)。

Botのルールについて
  • エントリー: 3日実績で検証済み(verified)かつAPRが一定以上の候補のみ、資金・取引所別・銘柄別の上限内で自動的に「発注したと仮定」する。瞬間値だけの候補には手を出さない。
  • エグジット: 対象の裁定機会が消滅した、net APRがマイナスに転じた、または保有期間が上限に達した場合に自動でクローズする。
  • 損益計算にはテイカー手数料の概算を往復・脚数分だけ差し引いている。実際の執行ではスリッページ・約定失敗リスクも発生するため、この数字はあくまで理論上の上限に近い。
  • このBotはAPIキーを一切使用せず、認証不要の公開データのみで動作している。
